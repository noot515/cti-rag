Existing repository data includes `benchmark/dataset.xlsx`, `config.yaml`, model material under `models/`, and runtime data roots under `./data`. Phases 00–13, 15, and 16 did not activate the new retrieval route or mutate the live legacy corpus/indexes.

**Production lexical choice remains MySQL 8 FULLTEXT.** The adapter has generation IDs, snapshot selection, security/temporal filters, deterministic ordering, and tombstone filtering, but the real MySQL service still requires execution evidence.

**Dense migration strategy:** do not rewrite the legacy KnowledgeBase collection in place. Build new compatible Milvus generations keyed by deterministic passage UID, publish them only through the shared snapshot catalog, and keep incompatible embedding fingerprints physically/logically separate.

**Actual integration evidence available today:** SQLite FTS5 executes persistently in GitHub Actions; DuckDB executes as a real analytical engine over preloaded registered tables. Phase 12 validates RFC exact/section retrieval, IPv4/IPv6 containment and longest-prefix selection, collector disagreement, historical DNS/BGP behavior, source snapshot replay, and distinct announcement/registration/RPKI graph semantics. Phase 13 validates SEC/FRED-style point-in-time revisions, ticker reuse and delisted universe membership, licensed-file price/corporate-action mechanics, independently specified returns/event-study calculations, and source-coordinate lineage. Phase 15 validates work/edition/passage identity, TEI/IIIF coordinates, original-vs-normalized OCR retrieval, uncertain historical intervals, translation/witness separation, source-role separation, and deterministic edition comparison. Phase 16 validates an actual composed exact + SQLite lexical + reference graph + DuckDB/event-study path with typed joins, ambiguity/time/missing-data variants, global budgets, fair context packing, citation coverage, and replay lineage. Dense semantic quality, real Milvus lifecycle/ANN behavior, actual reranker quality, the configured generator tokenizer, live cyber/network/finance/humanities source lifecycles, production market-data entitlement, and the missing Phase 14 prerequisite remain explicit gates.
